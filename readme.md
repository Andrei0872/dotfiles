# My dotfiles

## Prerequisites

```bash
brew install pngpaste
brew install lazygit
```

- `pngpaste`: lets Neovim paste clipboard images into markdown files (via `img-clip.nvim`).
- `lazygit`: used inside Neovim via `lazygit.nvim` (`<leader>lg`). Its config lives in `lazygit/config.yml` and is picked up automatically by the plugin.
